## M27 当前前端规则

M27 延续 M26 的三入口和退役边界；本节为当前规则，M1–M26 的界面与验收保留为阶段历史。课程、练习、实验、比较、影响、人工校准、通知写入及基础检查仍退役，旧写入口返回 `410 FEATURE_RETIRED`。本轮进度和实际证据唯一见[第四阶段计划 M27](phase-4-plan.md#m27)。

- 应用固定浅色：HTML 首屏 `data-theme=light`、`color-scheme: light`，根语义变量和 Ant Design `defaultAlgorithm` 一致。删除主题切换、深色算法、主题状态和 `theme-init.js`；不访问旧 `learning-lab.ui-theme`，不清除其他存储。错误页、搜索下拉、图和 Portal 同样使用浅色。
- 桌面顶栏约64px，品牌在左，17px三入口导航按页面中线居中，本地模式在右；768–1279px时导航以16px置于第二行，手机约64px并保留菜单。顶部搜索及其Ctrl/Meta+K聚焦入口已按用户批注移除，项目和日志页面搜索继续保留；源码目录筛选按后续批注移除，不保留隐藏的查询状态；无账号。蓝白面板、8–12px圆角、真实状态、清楚的键盘焦点统一用于五个工作区面板和对话框。
- `ScrollPanel` 替代 `ContentPager` 和位移测量算法：保留单一内容树、隐藏时草稿、焦点返回及实际记录分页，正文由有高度边界的面板滚动；搜索下拉和对话框也不再切内容页。源码和日志管理自己的内部滚动，不能叠加外层裁剪。Portal 的点击/焦点不驱动正文滚动。
- 项目管理采用主栏与约340px活动栏，上传ZIP、选择目录、创建空项目和导入已有项目复用原校验与幂等流程。每次展开一个项目并按需读取快照，进入快照一次性更新项目/快照URL。摘要来自快照数、文件数和准备状态；技术区分语言、依赖声明、源码使用，没有可用事实时明确显示“未识别”。技术筛选与最近导入/创建/名称排序由服务端先于分页执行。
- 活动状态只显示持久任务/日志阶段和事件时间，没有处理量不显示百分比。单根自动分析、多根选择、无根可读保持。删除仍预览范围、显式确认、检查忙任务；失败隔离可继续清理。
- 工作区左侧五项导航为源码、接口、关系、知识、讲解。源码文件树默认260px，多标签按文件身份去重；关闭当前标签选择邻近标签，关闭最后一个留空。主/副窗独立滚动，已有双引用URL恢复分屏；会话标签和滚动按快照隔离，普通导航保留项目、快照、分析、接口与引用，跨快照重建。
- 外壳底部说明栏已移除；五个工作区面板取消外层留白，沿现有flex/grid高度链填满顶栏下方可用宽高。项目管理与操作日志保留原外边距，面板内部间距、源码状态/跳行栏和矮屏局部滚动保持，不能用全局footer隐藏或额外100vh裁切正文。
- 源码页顶部仅显示项目名称一行，长名省略并由title提供完整文本；快照名称、页面名、完成统计及命名按钮不占用源码页标题区，其余四面板与项目管理的命名入口保持。识别失败、多根选择和任务恢复仍由原状态区承担，不能为压缩正常标题而隐藏异常反馈。
- 源码采用左目录、右文件标签和代码的紧凑布局。旧“项目文件”标题、筛选输入及接收计数移除，折叠与定位保留在紧凑目录工具区；分屏、解读和快照信息入口并入标签栏，路径面包屑不再占行。快照来源在本页保留屏幕阅读器文本及信息提示，其他SourceViewer消费者的来源展示保持。目录文件和标签只显示文件名，悬浮或键盘聚焦提示服务端已有的项目相对路径，不拼接主机绝对目录；关闭、固定和目录按钮有中文提示。提示复用Ant Design Tooltip，淡入淡出160/120ms、颜色反馈150ms；减少动态时停用颜色过渡，提示淡化缩短至1ms以保留结束事件，避免关闭等待组件兜底期限。标签“＋”以本实例引用打开并聚焦当前文件或首个目录，空树聚焦目录容器；窄屏关闭后回到实际打开按钮，不查询已删除的输入或跨实例DOM。
- 源码目录与代码使用局部分隔条调整宽度，默认260px、目录180–480px、代码至少320px；上限随容器可用宽度收缩。尺寸仅保留在当前快照会话，不写URL或持久存储；普通切页/切文件保留偏好。分隔条支持指针捕获、Escape取消、左右方向键10px/Shift加速40px与Home/End边界调整；窗口失焦、后台隐藏及卸载时结束捕获并清理监听。局部颜色反馈140ms，减少动态偏好禁用该过渡，不对宽度加动画。手机及不足以容纳两栏的容器沿用覆盖文件树，正文节点与滚动保持；两栏可用时局部重置旧网格行及目录的覆盖定位，不能继承旧窄屏隐藏规则。
- 每次读取200行，只按需加载相邻块；每窗口至多渲染1000行并限制一个相邻预取。切文件取消在途读取，迟到结果不污染新文件，失败块原位重试。跳转到行、真实可见范围/总行数/语言/编码/只读状态、只描绘已加载范围的缩略图均不预读整文件。高亮保持文本转义，不执行源码。
- 本页缩略图默认隐藏，在对应源码阅读区域悬浮或键盘focus-visible时显示，移到图上仍可点击；离开后淡出150ms并立即停用指针事件。保留68px占位与源码DOM，显隐不改变尺寸或滚动，双窗独立；手机继续隐藏，减少动态时取消过渡。点击按按钮坐标映射至已加载范围，空隙定位最近的已加载块，不预扫全文。共享SourceViewer在首次有效尺寸测量时恢复引用位置，隐藏窗口不以0高度重置位置；短文件和末尾定位后的可见范围按浏览器实际scrollTop计算，显式跳行引用仍使用用户请求行。
- 底部相关源码依据只聚合已保存接口、图和知识命中，不宣称完整反向引用。代码解读跳转原讲解流程，无接口时引导选择，保持预览、确认、显式提交和单实例草稿。
- 接口为列表/详情、关系为图/依据、知识为目录/正文、讲解为步骤/内容。宽度至少1280px保持完整工作区分栏及340px项目活动栏；较窄时通过按钮打开单实例模态活动侧栏，关闭或离开项目管理后停止轮询。双源码在宽度不超过1200px时切换阅读；日志在所有宽度统一使用约600px、受视口限制的右侧详情抽屉。768px以下采用紧凑横向导航和文件树覆盖层。表格/代码内部横向滚动，矮窗口末项可达。
- 已知分屏限制：既有1201–1599px样式会隐藏副窗且不显示窗口切换入口；本轮工作区扩展未修改该断点规则。实际观察及范围见第四阶段计划13.11，不能宣称该宽度分屏正常。
- 操作日志四张卡片为总数、失败、进行中、近7天成功率；统计继承关键词/类型/项目/时间，忽略结果及快捷状态、分页，界面明确范围。失败只含failed，进行中含submitted/accepted/running，成功率排除rejected/replayed/无终态，零分母显示暂无数据，差值显示百分点。
- 日志操作类型、结果、开始时间、结束时间在对应表头筛选；中文日历保留独立开始/结束时间的上下界和时分秒，应用后才查询，结果与快捷视图互斥。筛选/导出限制不再作为表格上方常驻提示。四种时间排序由服务端提供，空结束时间排最后。详情抽屉显示完整字段、真实事件、稳定错误、关联任务和同对象历史，恢复动作由服务端资格决定，提交再次校验。CSV导出当前完整筛选及排序结果，排除分页参数；最多10000条/10MiB，超限显式拒绝，UTF-8 BOM及公式防护，不含源码、秘密、原始事件或堆栈。零记录仍可导出表头；同步请求护栏防止重复启动，允许取消，并明确反馈成功、取消与失败。
- 日志使用“面包屑、主题色圆点标题、统计、左搜索右操作工具栏、有边框紧凑表格、底部居中分页”。复用Ant Design分页，默认20条，可选10/20/50/100；搜索、筛选、排序或页容量变化回到第一页并关闭详情，翻页也关闭详情，同查询后台刷新保留详情。非首页收到`PAGE_NOT_FOUND`回第一页重读，其他失败原位提示与重试。无日志删除或批量接口，不新增选择、删除和清空能力。
- 日志搜索200ms防抖、IME结束后查询，最多200个Unicode字符；完整查询键与AbortSignal隔离旧响应，清空立即恢复列表。输入内部无边框/outline/shadow，外层保留语义中性色焦点；筛选选择和日期框使用局部中性色边框反馈，不叠加蓝色焦点轮廓或阴影，自动聚焦、键盘选择、中文日历及筛选弹层Escape返回触发按钮保持。查询变化期间稳定表格容器，保留旧行时明确“正在更新”并禁用旧行操作；同查询后台轮询不清空列表或重置内部滚动。
- 日志抽屉支持遮罩、Escape、明确的键盘关闭按钮与焦点隔离，关闭回到触发入口；开合中快速关闭也恢复焦点。隐藏模块不保留可交互Portal并停止查询，不向隐藏页恢复焦点；筛选及页容量组件随激活状态重挂关闭内部浮层，已应用条件/页码/数量保留。按钮及行颜色过渡约150ms、抽屉约240ms、筛选浮层沿用组件约200ms开合；局部样式覆盖`prefers-reduced-motion`，不增加逐行入场或动效依赖。宽表格内部横向浏览，手机保留每页数量选择；窄屏、矮窗口及携带任务入口通过局部滚动保持分页可达，展开任务历史不裁切表格。

## 1. 技术与职责边界

基线为 React + TypeScript + Vite + Ant Design，M3 单工作区使用浏览器 History API 管理选择，TanStack Query 管理服务端数据；尚未引入 React Router。组件与交互满足[产品需求](requirements.md)，字段及错误遵循 [API 契约规范](api-conventions.md)，方法、路径和类型归属见 [API 清单](api-catalog.md)，目录与命名见[项目结构](project-structure.md#frontend-layout)，开发顺序见[阶段计划](phase-1-plan.md)。

首版不加入 Redux、Zustand 等额外全局状态库。M1-T01 版本与验证边界见下节，实际执行结果只在阶段计划记录；当前已有基础任务页面与 M3 导入/关联工作区，讲解、学习和固定实验面板已建立。

界面定位为桌面浏览器工作台，支持窗口缩小时调整分栏或切换面板，不要求首版具备完整手机操作体验。不能因窗口变窄让关键按钮和反馈不可达。

### 1.2 参考环境及验证范围

- Windows x64：使用 `.runtime/tools` 中经过官方 SHA-256 核对的 Node 24.21.0/npm 11.19.0，保持全局安装不变。`.node-version`、`engines`、`packageManager` 和 `.npmrc` 相互核对，版本不符应失败，不静默退回全局工具。
- Linux amd64：使用 Node 24.21.0 的 Debian Bookworm 临时镜像，将实际 digest 固定在检查入口，并在容器内重新 `npm ci`。不挂载或复用 Windows `node_modules`，以实际验证平台相关构建包；`.runtime/linux-cache/frontend` 只复用 npm 下载缓存，每次创建新的 `node_modules`。
- 本任务仅建立 `tooling/ToolchainProbe.tsx` 及对应测试，验证 Ant Design 渲染、React 事件与重新挂载。Vite 使用专用配置按库构建，输出至被忽略的 `.runtime/frontend-tooling-dist`；没有 `src/app`、HTML 应用入口或业务页面。
- jsdom 是测试 DOM，不是完整真实浏览器；工具构建成功不能推导 AT-23/AT-25 已通过，浏览器和端到端测试仍待相应任务。
- M1-T01 当时未预装 React Router、TanStack Query、Playwright 或 API 类型生成工具；M1-T02 新增范围见 1.4。

### 1.3 声明兼容问题与受控补丁

2026-09-28 首次 Windows 与 Linux 临时容器实测：精确版本核对和 ESLint/TypeScript 负向检查通过；`npm run typecheck` 在 `strict: true`、`skipLibCheck: false` 下返回两个 TS2430：

- 锁定的 `@rc-component/image@1.10.0`：`GroupPreviewConfig.imageRender` 把父类型可缺省的 `current` 改为必填，回调参数类型不兼容。
- 锁定的 `@rc-component/picker@1.12.2`：`SinglePickerPanelProps.defaultValue` 接受 `null`，父类型不接受，接口继承不兼容。

这是实际安装的第三方声明错误，不能用 peer 范围合法或 Vite 构建通过代替严格类型检查。首次调查时官方 registry 的 Ant Design 最新版为 6.6.5、image 最新版为 1.10.0；picker 最新版 1.15.0 超出 Ant Design 的 `~1.12.2` 约束，并且不能解决 image 的错误。首次验收因此受阻，失败历史保留在阶段计划。

用户随后明确选择最小类型补丁。`tooling/type-patches.json` 记录两个包的精确版本、修改理由、四个声明文件及修改前后 SHA-256：image 的父类型改为 `Omit<InternalPreviewConfig, 'imageRender'>`，picker 的父类型改为 `Omit<BasePickerPanelProps<DateType>, 'defaultValue'>`，保留各自已有的专用属性；同时处理 `es` 与 `lib`，不改变 JavaScript 实现。

`postinstall` 使用 Node 内置 API 应用补丁，不增加依赖。全部文件通过校验后才写入，未知版本、内容或缺失文件会失败；重复应用不重复修改，写入故障会尝试恢复并报告错误。`verify:versions` 只读核对补丁已应用，`test:tooling` 验证失败路径、两种声明分发的合法输入及错误输入。保留 `strict: true`、`skipLibCheck: false`。这是由本项目承担维护责任的临时修复，并非官方原包已通过检查；未来依赖升级须重新验证并在上游修复后移除。两个原包均为 MIT，保留随包许可证；修复仅影响开发期类型检查，不增加浏览器运行代价。

来源：[上游同类问题](https://github.com/react-component/picker/issues/764)、[image 类型源](https://github.com/react-component/image/blob/master/src/PreviewGroup.tsx)。以本项目实际诊断为验收依据，上游关闭问题的状态不代表本项目已修复。修复后两个平台的全新安装、补丁状态、严格类型检查、lint、格式、2 项组件测试、10 项工具测试及构建均通过。安装体积、耗时及完整命令统一见阶段计划。

## 2. 业务模块与组件组织

拟按项目导入、分析工作区、学习、实验组织功能模块。每个模块聚合其页面、业务组件、查询 hooks、API 调用和必要类型；共享层只放真正跨功能使用的客户端和通用组件，应用主题由 `src/app/` 统一配置。依赖方向为 `app → features → shared`；跨功能流程由应用层组合，不深入导入其他 feature 的内部实现。

- 页面负责布局、路由参数和业务区域组织，不直接处理复杂请求编排。
- 业务组件负责清晰的单一交互，不兼任接口客户端或跨模块数据仓库。
- 自定义 hooks 封装可复用状态流程与副作用；不把所有页面逻辑机械搬入一个巨大 hook。
- API 模块定义资源请求和转换，统一客户端负责传输、CSRF、HTTP 错误解析与取消。
- 按职责和复用需求拆分，不以固定行数强制拆分，也不为一次性简单展示创建复杂抽象。

TypeScript 开启严格模式。领域对象和接口参数显式类型化；外部数据从未知输入进行边界验证，不使用 `as` 或 `any` 绕过可预见的不确定性。新增或实质改写的代码注释使用简体中文。

现有任务历史兼容 `analysis`：排队起即要求 snapshot_id，成功只接受分析结果同源路径，非成功不接受结果链接；显示所属快照，不向 system-checks 请求分析结果。四个分析操作生成类型已经加入；M3 已建设分析提交表单、接口目录与工作区，详情见下文。

## 4. 状态模型

| 状态类别 | 维护位置 | 规则 |
| --- | --- | --- |
| 项目、快照、任务、讲解、作答和实验记录 | TanStack Query | 后端是持久化来源，按资源及快照构建查询键 |
| 当前项目、快照、接口及需要分享或恢复的筛选 | URL | 校验参数，缺失资源给出明确页面状态 |
| 面板展开、尚未提交的答案、临时筛选输入 | 组件状态或局部 reducer | 保持最小范围，离开对象时按规则清理 |
| 从现有数据可算出的选中节点等值 | 派生计算 | 不再存一份容易失配的副本 |

服务端数据不复制到独立全局仓库。React 官方指出冗余或重复状态容易导致同步问题；TanStack Query 用于异步服务端数据的获取与缓存。[React 状态管理](https://react.dev/learn/managing-state)、[TanStack Query 概览](https://tanstack.com/query/latest/docs/framework/react/overview)

查询键至少包含决定结果归属的项目、快照和资源标识，题目还需区分版本。切换快照时不得保留上一快照结果作为当前结果的占位内容；可继续缓存旧数据，但不能显示为新对象。

## 5. 请求与异步副作用

- 请求使用统一客户端及模块 API，路径为同源相对地址；字段命名、分页和错误对象不在组件中重新定义。
- 通用客户端位于 `src/shared/api/client.ts`，功能请求位于 `src/features/<功能>/api/`。从 `contracts/openapi.yaml` 生成 `frontend/src/shared/api/generated/schema.d.ts`，功能模块通过明确别名引用，不手写第二份相同 DTO，也不手改生成文件。生成类型不等于运行时数据已校验；渲染前核对必要标识、任务状态、引用和内容结构。
- 查询传递取消信号，卸载或失去用途时结束订阅；服务器任务是否停止以任务 API 为准，浏览器取消不是任务取消。
- 定时轮询只在相应任务处于 `queued` 或 `running` 且页面需要结果时进行，初始间隔 2 秒；后台标签暂停，返回前台时刷新。终态或卸载后清理计时器。
- 只读 GET 在明确的网络暂时故障或可恢复 5xx 时最多自动重试一次，不重试校验、权限或不存在错误。
- 写入、模型调用和实验触发不自动重发。提交前创建并保存该操作的幂等键；结果未知时使用相同键恢复请求，用户明确开始新尝试时才生成新键。
- 防重复按钮只是体验措施，后端幂等仍是最终保障。刷新后通过持久化任务列表恢复，不依赖组件内临时对象作为唯一记录。
- 迟到结果只能写入其对应查询键，不能通过闭包或全局变量覆盖当前选中对象。
- 不在渲染阶段或无用户意图的 Effect 中触发计费调用、作答提交或实验运行；开发环境 Effect 重放不应产生业务副作用。

v0.1 不提供服务端任务取消功能，也不展示会让用户误以为已停止计费或执行的取消按钮。可以关闭结果面板，后台任务仍由服务端管理。

## 6. 统一交互状态

每个数据区域明确覆盖以下状态：

| 状态 | 界面要求 |
| --- | --- |
| 尚未选择或未开始 | 说明下一步操作 |
| 首次加载或任务排队 | 展示真实状态，不虚构百分比 |
| 正在执行 | 展示当前阶段和已有处理量，可查看任务标识 |
| 无结果 | 区分没有文件、没有支持的接口和没有匹配关系 |
| 部分结果 | 展示可用内容和未解析摘要，不用绿色成功提示掩盖缺口 |
| 失败 | 显示可理解原因、适用的恢复操作和可复制请求标识 |
| 结果存在但不适用 | 说明快照、题目版本或实验来源不匹配 |

Ant Design 表单反馈用于字段错误，页面级错误用于持续故障，通知用于短暂事件。长任务不能只靠短暂 Toast 表达状态；同一错误不在多个层重复弹出。

编辑器区域只读，按行显示源码；选择引用时保留上下文和相对路径。点击失效引用时说明原因，不跳转到最接近的其他文件来模拟成功。

## 7. 样式、可访问性与内容安全

- 主题统一维护颜色、字号、间距和圆角，优先使用 Ant Design 主题能力；公共组件保留一致行为。
- 不随意添加第二套组件库。专用图或代码展示库仅在原有能力不足时引入，并记录必要性、维护与许可证检查。
- 所有交互有可读名称，键盘能进入和离开弹窗、选择节点、提交练习；关闭弹窗后恢复合理焦点。
- 色彩之外使用图标或文字表达“已识别、推断、未解析、失败”等状态，避免仅凭红绿判断。
- 图之外保留可读的步骤或关系列表，保证复杂图不成为理解和无障碍操作的唯一入口。
- 源码始终作为文本渲染；模型 Markdown 禁止原始 HTML，链接只允许经校验的安全协议，不使用未经处理的 `dangerouslySetInnerHTML`。
- 图节点、标签和引用来自受控结构化数据，不执行模型提供的脚本、HTML 或任意图代码。
- 本地存储只可保留无敏感内容的界面偏好及必要幂等标识，不保存模型凭据、源码正文或完整模型请求。敏感内容不写浏览器日志。

## 8. 前后端协作

API 的 `snake_case` 字段在生成类型和传输边界保持一致，组件内部变量采用 TypeScript 常规命名，不做全局隐式字段转换。

当前本地入口为 `http://127.0.0.1:5173`，由 Nginx 提供静态页面并同源代理 `/api/`；配置说明见根目录 `.env.example` 和 README。独立 Vite 开发代理留待确需时建立，不应把 `vite` 默认监听当作完整应用启动。CSRF 获取和提交通过统一客户端完成，不能靠关闭服务端保护或设置宽泛 CORS 解决联调问题。

前端不接收服务端模型密钥，不自行访问供应商，也不推断数据库或 Worker 状态。服务端声明的任务状态、快照和错误代码通过 [API 契约规范](api-conventions.md)解释。

接口变更先更新对应接口表，再实现并导出 OpenAPI、生成类型和执行契约验证。同一变更更新查询键、失效规则和必要页面状态，避免字段虽然编译通过但结果归属错误。

### M3 工作区实际行为

默认入口是项目工作区；`?view=jobs` 保留原系统任务页。URL 保存 project、snapshot、analysis、endpoint、node、job 以及源码 file/start/end；非法、重复或缺失上级归属的地址明确拒绝。浏览器前进、后退和刷新恢复选择。页内项目、快照、接口和历史列表分别分页，源码按最多 200 行分段请求。

Query 键包含资源归属，读取传递 AbortSignal；切换时按资源重新挂载，没有旧结果占位。文件路径必须通过当前快照清单找到唯一文件，再核对行范围和内容响应的身份/摘要；失效引用不回退其他文件。图查询的接口视角只请求该接口上游与后端下游；全图入口保留未匹配请求。证据、候选、覆盖限制、历史缺失、加载、失败和截断分别呈现。该段记录 M3 原布局的局部滚动；M23 可视区域内容分页也仅保留为历史，当前纵向访问采用 M27 有界面板滚动，键盘与窄窗口要求继续保留。

`useIdempotentOperation` 在发送前将 UUID 和输入 SHA-256 写入 sessionStorage，不保存 ZIP、项目源码、凭据或完整输入。未知结果恢复时必须重新提供相同输入；有任务链接优先查询，提交不自动重发。离开原组件会取消请求，迟到成功回调不能切回旧工作区。可确定的新请求拒绝清除待确认标识，恢复旧操作的失败保留标识。会话存储不可用时拒绝提交，不能降级为无幂等保护的写入。

M3 沿用 React、Ant Design 与 TanStack Query，不引入额外依赖。浏览器验收使用工具提供的真实浏览器；未给工程安装 Playwright。M3 当时未提供学习、讲解及实验；当前 M4、M5 扩展见下文。


### M4 讲解与学习工作区

M4 初始工作区组合 explanations/learning 功能，以「源码关系／讲解／练习」面板切换及宽窗右侧区域呈现；该布局属于阶段历史，当前独立页面见 M21。URL 标识 preview、explanation、attempt 必须绑定分析和接口；刷新恢复历史对象与所属模块。查询键包含快照、分析、接口和对象/内容版本，切换接口清理旧对象标识，迟到响应不切回旧选择。

预览逐项展示目标、模型、模板、片段、完整消息和实际字节数，不截断消息或片段来满足旧预算。保存确认与提交讲解为不同按钮，前者无外发；用户拒绝不提交确认或任务。浏览器仅保留确认 UUID 和未确认操作的 UUID/摘要，不存正文或模型密钥。CONSENT_STALE 等明确未受理错误可释放原操作键，未知网络结果保留原键恢复；所有 POST 禁止自动重发。

页面说明应用不设置模型输出上限、请求总期限或消息字节预算，费用和供应商默认限制由用户判断。结果分别显示报告的输入、输出和总用量，缺失显示未知，不估算费用。历史预览保留原预算字段并标明已失效，禁止保存确认或提交，须准备新预览；历史失败与旧讲解仍可读。非法响应、拒答、截断及引用错误仍显示失败，不自动重新确认或重发。

讲解结构化纯文本渲染，没有 HTML、Markdown 执行、外部链接或可执行图。事实、推断、通用原理分别标明；来源沿用受控源码定位，并始终提示位置核验不等于结论正确。三类练习采用键盘可操作排序按钮、状态/记录数输入及文件/行号输入；提交前不显示答案。匹配失败仅显示无对应练习。历史绑定题目与答案版本，正确率及提示不等于掌握评估。

### M5 实验交互

labs feature 只通过生成 DTO 和同源 API 访问工作台。四种固定输入的预测必须先填写，不预填预期；保存后的预测与真实响应并列展示。页面明确示例版本、实际 HTTP 状态/正文/计数、运行失败及部分观测。响应正文只作文本显示。清理未确认有文字说明，不能以成功颜色或预设答案代替。

URL 的 run UUID 属于所选分析/接口；运行时校验同时验证快照、分析、实验 Job、运行路径及清理身份，跨上下文结果拒绝显示。切换快照/接口或开始新任务时清除旧 run，查询按所属资源构造键；刷新或从分页历史选择可恢复运行。当前任务通过 job_id 独立查询所属运行，不依赖历史当前页是否包含新记录。提交复用共享幂等 hook，取消只影响客户端等待，未知结果保留键；LAB_VERSION_MISMATCH/LAB_NOT_APPLICABLE 是确定性拒绝，释放键允许修正后新提交。失败重试沿用任务组件，创建新尝试，不覆盖旧运行。

验收包括必填预测、错误预测原样保存、响应独立显示、确定性冲突后重新提交、失败无观测/清理未知、刷新恢复、键盘和窄窗口。测试定位按钮时允许 Ant Design 的加载图标附加可访问名称，但继续断言实际提交次数和不同尝试的操作键。

### M21 统一工作台、双主题与源码窗口（历史，主题与滚动由 M27 替代）

### 9.4 M23 可视区域分页（历史，组件已由 M27 移除）

`shared/components/ContentPager` 保留单一内容树，依据容器高度、文字行、控件与记录边界分配可见页；`content-pagination.ts` 负责纯分页计算。并列内容没有共同断点时下一页承接跨界部分，短块与控件仅在完整容纳的页显示。禁止用固定裁剪高度替代尾部可达性验证。`ResizeObserver` 和受限属性的 `MutationObserver` 负责尺寸、展开与异步内容变化，非激活模块停止观察，卸载释放观察器和动画帧。

外壳占用 `100dvh`，模块标题和底部翻页入口保持可见，所有模块主体以及快照命名面板使用同一分页组件。页码仅为当前布局状态，不写入业务存储；新资源、查询批次及源码搜索改变时回到首页，单纯切换模块保留页码和同一表单。键盘聚焦或原生校验可定位目标页，正文支持 PageUp/PageDown，输入控件保留原键盘语义。

`pagination.css` 解除只读正文、源码、文件树、图面板和结果文本的内部纵向滚动，交由页面分页。宽源码与关系画布保留横向查看，窄屏源码长行换行；图内依据改为画布区域中的内容块，打开后聚焦并显示所在页。窄屏文件树展开参与分页，搜索会显式展开文件入口。以上规则替代 M3/M21 文中历史布局的纵向滚动与文件树浮层描述。业务选择框原宽度约束保留，页码控件使用紧凑固定宽度。

`SystemStatusPage` 只承担显式检查、原键恢复、当前检查查询和结果；`JobsPage` 只读取历史并提供结果入口。两者沿用 jobs 的公共出口与查询缓存，未激活时停止本页查询与轮询；`SystemStatusSummary` 仍只反映最近已加载 20 条记录范围。历史检查结果在系统状态查看，反复选择同一记录仍切回该次结果。历史批次使用 History API 保留项目、快照和分析上下文，兼容 `view=jobs&page=…`。实际验证唯一见[第四阶段计划 M23](phase-4-plan.md#viewport-pagination)。

### 9.5 M24 分类导航与统一呈现（历史）

`app/workspace-navigation.ts` 维护模块名称、四分类映射和每类最近模块；工作台 1 个模块，项目分析 6 个，学习实验 3 个，系统 2 个。分类记忆只存在于外壳实例，首次默认选择各类首个模块，URL 刷新或历史导航仍按合法 section 推导所属分类。`WorkspaceShell` 不增加业务查询或写入，桌面只显示当前分类侧栏，工作台不显示二级侧栏；窄屏模态菜单按组提供全部入口，保留原模态、快捷键和焦点规则。

`ThemeProvider` 与 `global.css` 使用蓝灰语义变量，Ant Design 的主色与背景、文字和边框保持一致；浅色蓝色主操作、灰白画布与白面板，深色深蓝画布与蓝灰面板。顶栏跟随主题：浅色为白底深色文字和浅灰搜索框，深色保留原渐变与白色文字；导航选中、悬停、搜索背景和辅助文字由对应顶栏变量维护。M25 实心按钮使用两主题统一的 #1767d8 主色与白字，悬停 #1b6bd5、按下 #1359bb；深色/浅色蓝灰语义背景保留，Ant Design token 与 CSS 一致，普通文字对比至少为 4.5:1，颜色回归同时覆盖两主题的默认、hover 和 active 状态。主题偏好、同源首屏脚本、CSP 和减少动画规则沿用 M21，不用主题切换重建业务组件。

`shared/components/PagePresentation.tsx` 的 `PageHeading` 统一标题和说明，`ContentState` 统一缺少前置、加载、空结果和错误呈现；错误使用 alert，加载使用 status，仍由调用者传入真实内容与原操作。`Feedback` 复用该呈现，继续显示原错误消息、请求标识和显式重新查询；机器错误转换仍归统一 API 客户端。关系页页头保持屏幕阅读器可读，视觉仍直接展示图。

`shared/components/RecordList` 仅消费当前已读取记录和列渲染函数：桌面使用 Ant Design Table，pagination=false 且无 scroll.y；768–1199px 不固定列宽，按内容分配可用空间；<768px 渲染单份卡片，标题列不重复挂载。行/卡片以 data-page-keep 参与原 ContentPager；选择使用稳定资源键与原按钮。projects 的清单展示真实名称、时间和文件数，analysis 的清单保留方法/路径/对象及原接口选择，jobs 保留类型、时间、状态与检查结果入口。任务完整 ID、错误代码/明细/诊断标识、快照和重试关系在单个可折叠 details 按记录查看，选中后焦点定位该区，不新增查询。

`PageControls` 的“上一批记录／下一批记录”读取服务端列表批次，固定底部的“上一页内容／下一页内容”只移动已读内容；表格不提供另一套记录分页或纵向滚动。服务端默认每批 20 条及原 URL 参数保持，源码每段 ≤200 行继续独立于屏幕内容页。选择批次、资源、展开详情和窗口变化继续按 M23 重算，原草稿和幂等恢复不重建。

`KnowledgePanel` 以当前已读卡片构建知识目录，只挂载所选正文，当前批次无已选卡片时展示首条；版本、适用性和维护说明来自原 DTO，`LearningPathPanel` 的课程/先修与练习边界不变。用户选卡后等待正文渲染与分页测量的两帧，再以 preventScroll 聚焦正文区域，同卡再次选择也可定位；快速选择仅定位最后一项，初始读取、隐藏模块和换批次不抢焦点，卸载取消尚未完成的帧。

`ExplanationPanel` 的三个步骤只表示现有预览、确认与生成状态，完整消息、片段、来源和拒绝入口仍可审阅；步骤提示不新增调用、自动确认或自动重试。完整预览的 pre 使用 pre-wrap 与 overflow-wrap:anywhere，保留原文本并随可视区域分页，不以横向截断代替审阅；拒绝、保存确认和提交按钮组以 data-page-keep 保持完整可达。

Ant Design Table 的媒体查询行为在 jsdom 中由 `tooling/test-dom-setup.ts` 提供随 resize 更新的测试替身并释放监听器，不是生产 polyfill，也不代替真实浏览器排版。FR-24/AT-70–74 定义验收，M24 的进度、实际结果和限制唯一记录于[第四阶段计划](phase-4-plan.md)；M21–M23 的历史证据保留。

### 9.6 M25 图片首页与显式记录（历史）

首页隐藏重复的可见页头并保留无障碍 h1；Hero、准备、快捷入口及下部三面板随宽度排列，装饰 SVG 不表达业务状态。顶栏 68px，768–1199px 双行，窄屏沿用原模态导航；底栏参与剩余高度，低于 600px 隐藏插画与副标题，业务内容继续同树分页。其余 11 页面主体布局保持；公共面板圆角 8px、控件 4px，正文 14px、辅助 12px。

全局搜索由 `WorkspaceShell` 的搜索插槽挂载唯一 `WorkspaceSearch`，顶栏直接输入，不再点击入口后放大或打开第二个输入框。仅在当前输入包含有效关键词、组合输入结束且防抖查询与当前关键词一致时，在原框下方展开非模态结果；空值或纯空白时聚焦、点击和快捷键均不显示下拉，清空立即收起并取消请求，换词期间不显示旧词结果。宽度受视口限制，高度按输入区底边与剩余视口计算；结果沿用 `ContentPager`，不锁背景或困住 Tab。Ctrl/Meta+K 聚焦顶栏输入，有有效关键词且输入已聚焦时可重新展开；Escape 收起并保持输入焦点，组合输入期间不处理 Escape 或方向键。点击外部或焦点离开整个搜索区收起结果，关键词保留；结果选择沿用原导航。

搜索保持 200ms 防抖、组合输入结束后查询、空输入零查询及 200 Unicode 字符上限；项目/接口使用各自 q，文件复用完整已读清单，原索引定位保留。分组分别翻记录批次，局部失败不隐藏成功组。关闭、换关键词/分页/上下文取消旧请求；上下箭头选择结果，跨内容页焦点由 `ContentPager` 显露。源码页面独立文件过滤不与全局关键词共用。

顶栏搜索不显示 Ctrl K 提示徽标，快捷键功能继续保留。搜索输入内部不叠加蓝色焦点轮廓，聚焦时仅用整个搜索框的边框颜色反馈；覆盖仅限顶栏搜索输入，不改变其他控件的键盘焦点提示。

通知只查询真实 succeeded/failed 任务，前台 5 秒轮询、后台暂停。打开/查看不 PATCH；逐条标记或按响应 as_of 全部已读才写入服务端，未知结果只读取核实。任务详情按 ID 可在列表之外恢复，异步结果导航验证资源归属；改选任务或工作区时取消旧结果读取。

课程进度按课程版本、精确卡片计算；独立 course URL 可直接阅读，不放宽原 curriculum/goal 的 endpoint 约束。仅显式已学/撤销 PATCH，所有 GET 零创建记录；首页前三课程的已学/总数是用户学习记录，不代表掌握。课程切换与迟到写入不污染新对象，未知结果查询同课程进度核实，不自动重发。

新增行为的状态、回归、隔离环境和浏览器证据唯一在[第四阶段计划 M25](phase-4-plan.md#m25-workbench)，FR-25/AT-75–83 定义验收，不增加模型调用、账号和新依赖。
